Accounts on your watch

Keep Quota Watch open on your watch. Select it in desktop Chrome or Edge, then enter the six-digit code from the watch when your computer asks.

Can't find your watch?

Turn on Bluetooth and disconnect the watch from other browser tabs or computers. On macOS, allow your browser under System Settings → Privacy & Security → Bluetooth.

Add or update a subscription

Select an exported account card, check the email address, then save it to your watch.

Export a Claude or Codex account card

Clone the Quota Watch repository. Use a separate client profile and output file for each account.

ChatGPT / Codex

From the repository, run this with the Codex profile you want to sync. Use codex login first if needed.

python3 tools/account_card.py codex --out ~/Downloads/codex-watch.json

Claude

In your signed-in Claude Code profile, use the following status line command in settings.json. Replace both paths with absolute paths. Claude Code writes the card when it updates the status line.

{
  "statusLine": {
    "type": "command",
    "command": "python3 '/path/to/quota-watch/tools/account_card.py' claude --out '/path/to/claude-watch.json'"
  }
}
